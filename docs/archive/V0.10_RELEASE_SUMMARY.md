## 2. Runtime architecture (v0.10)

```
ToolOutcome → normalize_tool_outcome() → advance_from_outcome() → TMS shadow
                                              ↓
                         guards / dedup / backup gate read TMS shadow
                                              ↓
                         checkpoint save → mutation_state_json (v2 only)
```

| Concern | v0.10 behavior |
|---------|----------------|
| **Advance** | `advance_from_outcome()` only |
| **Guards / dedup** | TMS readers (`check_mutation_allowed`, `should_skip_tool_tms`) |
| **Checkpoint write** | `mutation_state_json` required; v1 columns NULL |
| **Checkpoint read** | v2 → v1 merge → empty (v0.9 compat preserved) |
| **Resume** | Hydrate → TMS shadow; hint from `build_tms_resume_hint()` |
| **Re-backup UX** | `clear_tms_backup_milestones()` on keyword follow-up |
