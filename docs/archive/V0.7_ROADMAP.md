## 1. 版本目标

v0.7.0 在 v0.6.0 **Index + Context Budget + Cancel/Checkpoint** 之上，增加 **RAG 语义增强层**：

| 支柱 | v0.7 答案 |
|------|-----------|
| **RAG kernel (C1)** | chunk + embed + Chroma store + `python -m rag.build` |
| **Hybrid search (C2)** | `search_in_repo` 内部 grep + symbol + semantic merge |
| **Propose expand (C3)** | task → semantic candidates → 现有 ranking / budget |

**原则**：RAG 是增强层，不替代 Index；**不新增 ReAct 工具**；**`RAG_ENABLED=0` 默认关闭**。
